# 🛒 쇼핑 리스트

사야 할 물건을 추가·수정·삭제·체크할 수 있는 간단한 웹 앱입니다. Streamlit으로 만들었습니다.

## 기능

- 아이템 추가 (이름 + 수량 1~99), 수정, 삭제
- 체크하면 취소선과 흐린 글씨로 표시, 전체/미완료/완료 필터
- 진행 현황("전체 N개 중 M개 완료")과 진행 바
- 삭제 직후 되돌리기, 완료한 항목 일괄 삭제(확인 단계 있음)
- 같은 이름의 항목을 추가하면 알려 줌
- 모바일 화면과 라이트/다크 테마 지원

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 http://localhost:8501 을 엽니다. Streamlit 1.58 이상이 필요합니다.

## 데이터 저장 방식과 한계

목록은 서버가 아니라 **사용하는 브라우저의 `localStorage`**에 저장됩니다.

- 새로고침하거나 서버가 재시작돼도 목록이 유지됩니다.
- 사용자마다 자기 브라우저에 따로 저장되므로 다른 사람의 목록은 보이지 않습니다.
- **다른 기기나 다른 브라우저와는 공유되지 않습니다.** 브라우저의 사이트 데이터를 지우면 목록도 지워집니다.
- 같은 브라우저에서 탭 두 개를 열면 한쪽에서 바꾼 내용이 다른 쪽에도 반영됩니다. 이때 다른 쪽 탭은 자동으로 새로고침됩니다.
- 브라우저가 저장을 막은 경우(일부 개인정보 보호 설정)에는 경고가 뜨고, 새로고침하면 목록이 사라집니다.

기기 간 공유가 필요하면 Supabase 같은 외부 DB 연동이 필요합니다.

## 배포 (Streamlit Community Cloud)

1. 이 폴더를 GitHub 저장소로 올립니다. (`app.py`, `requirements.txt`, `.streamlit/config.toml`)
2. [share.streamlit.io](https://share.streamlit.io)에서 저장소와 `app.py`를 지정해 배포합니다.
3. 발급된 `*.streamlit.app` 주소로 접속합니다.

## 구성

| 파일 | 설명 |

| `app.py` | 앱 전체 (화면, 로직, 브라우저 저장) |
| `.streamlit/config.toml` | 테마 색, 사용 통계 전송 끄기 |
